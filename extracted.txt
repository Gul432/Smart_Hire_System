Project Title
SmartHire AI – Resume Screening and Candidate Ranking System
Project Description
SmartHire AI is an AI-based web application that helps companies shortlist the best candidates for a job. HR uploads multiple resumes and a job description, and the system automatically analyzes resumes, extracts skills, compares them with the job requirements, and ranks candidates from best to worst.
The system saves time for companies by reducing manual resume screening and helping HR quickly identify the most suitable candidates.
Main Features
Upload multiple resumes in PDF or DOCX format 
Upload job description 
Extract text from resumes automatically 
Identify important skills, education, experience, certifications, and projects 
Match resume content with job description 
Give each candidate a matching percentage score 
Rank candidates from highest to lowest 
Show missing skills for each candidate 
Generate shortlist of top candidates 
Search and filter candidates 
View candidate profile summary 
Generate downloadable PDF report for HR

AI Logic
Step 1: Resume ParsingThe system reads the uploaded resume and extracts text.
Step 2: Skill ExtractionThe system finds important skills such as Python, Java, SQL, teamwork, leadership, etc.
Step 3: Job Description AnalysisThe system extracts required skills from the job description.
Step 4: Matching AlgorithmThe system compares candidate skills with job requirements using:
